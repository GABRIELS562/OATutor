# SA CAPS Mathematics Content

South African CAPS (Curriculum and Assessment Policy Statement) Mathematics content for Grades 10-12.

## Focus Areas (Paper 2)

This content library focuses on **Paper 2 topics** where students struggle most:

| Topic | Marks | Grade Level |
|-------|-------|-------------|
| Euclidean Geometry | 50 | 10-12 |
| Trigonometry | 40 | 10-12 |
| Analytical Geometry | 40 | 10-12 |
| Statistics | 20 | 10-12 |

## Content Sources

Questions extracted from:
- NSC (National Senior Certificate) Past Papers (2019-2024)
- DBE (Department of Basic Education) Official Exams
- Provincial Trial Exams

## Naming Convention

Problem IDs follow this format:
- `geo-` = Euclidean Geometry
- `trig-` = Trigonometry
- `anl-` = Analytical Geometry
- `stats-` = Statistics

Followed by subtopic and number, e.g.:
- `geo-tangent-001` = Tangent theorem problem #1
- `trig-compound-001` = Compound angle problem #1
- `anl-circle-001` = Circle equation problem #1
